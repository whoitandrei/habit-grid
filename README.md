# HabitGrid

Идея и целевая аудитория описаны в [VISION.md](VISION.md).

## Планируемый объём работы (MVP)

### Основные пользовательские сценарии

1. **Настройка привычек.** Пользователь создаёт до 4 ежедневных привычек: задаёт название каждой, может переименовать или удалить привычку.
2. **Просмотр календаря.** На главном экране отображается календарь текущего месяца. Каждая дата разделена на 4 ячейки, каждая ячейка соответствует одной привычке. Пользователь может листать месяцы назад и вперёд.
3. **Отметка выполнения.** Пользователь выбирает день и отмечает выполненные привычки — их ячейки закрашиваются зелёным. Пока текущий день не закончился, неотмеченные ячейки остаются пустыми. После окончания дня все неотмеченные ячейки автоматически закрашиваются красным. Отметку за прошедший день можно исправить: красная ячейка становится зелёной и наоборот.
4. **Настройка напоминаний.** Пользователь включает или выключает ежедневное уведомление и выбирает время, в которое оно приходит.
5. **Получение напоминания.** В заданное время приходит уведомление с просьбой отметить выполнение привычек за день. Нажатие на уведомление открывает приложение на текущем дне.
6. **Итоги месяца.** Пользователь открывает экран анализа за выбранный месяц и видит процент выполнения по каждой привычке и общий процент выполнения за месяц.

### Критерии готовности

Приложение считается готовым, если:

- [ ] можно создать, переименовать и удалить привычки, но не больше 4 одновременно;
- [ ] главный экран показывает календарь месяца, где каждый день разделён на 4 ячейки;
- [ ] переключение между месяцами работает корректно;
- [ ] отметка выполнения закрашивает нужную ячейку зелёным, отметку можно снять;
- [ ] после окончания дня все неотмеченные ячейки автоматически становятся красными;
- [ ] за прошедшие дни можно исправить отметку;
- [ ] в итогах месяца неотмеченные прошедшие дни считаются невыполненными;
- [ ] все данные сохраняются локально и не теряются после перезапуска приложения и устройства;
- [ ] уведомление приходит ежедневно в выбранное пользователем время;
- [ ] нажатие на уведомление открывает приложение на текущем дне;
- [ ] уведомления можно отключить, время можно изменить;
- [ ] экран итогов показывает процент выполнения каждой привычки и общий процент за выбранный месяц;
